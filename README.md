# TestFastAPI
## Краткое пояснение:  
Проект представляет собой разработку микросервиса на Python с использованием фреймворка FastAPI,
сопровождающегося набором автоматизированных тестов. 
Основная цель — создать надежный и масштабируемый сервис, 
обеспечивающий возможность тестирования RESTful API. 
Проект ориентирован на повышение качества разработки и тестирование приложений,
обеспечивая автоматическое выполнение тестовых сценариев и проверку функциональности сервисов.
Название подчеркивает основную направленность проекта — автоматизация тестирования 
и профессиональный подход к разработке. 

## Установка зависимостей  
pip install -r requirements.txt

## Запуск FastApi  
uvicorn app.main:app --reload
поумолчанию запустится по http://127.0.0.1:8000/

## Документация 
http://127.0.0.1:8000/docs

## Запуск тестов
pytest  
можно запустить на другой url изменив переменную baseUrl  
pytest --baseUrl=http://localhost:8000
