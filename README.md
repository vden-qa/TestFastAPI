# TestFastAPI 🚀  
## Описание 📌  
Этот проект предлагает мощный микросервис, разработанный на Python с применением фреймворка FastAPI, дополненный обширным набором автоматизированных тестов. Основная задача — создание надежного и легко расширяемого сервиса для эффективного тестирования RESTful API. Проект нацелен на улучшение качества разработки программного обеспечения путем автоматизации тестирования и проверки функционала служб.

## Установка 🔧  
Для начала установите необходимые зависимости командой:  
pip install -r requirements.txt

## Запуск приложения 🚢  
Запустите приложение следующим образом:  
uvicorn app.main:app --reload

По умолчанию оно заработает на адресе  
http://127.0.0.1:8000.

## Документирование API 📄  
Документацию по вашему API можно просмотреть тут:  
http://127.0.0.1:8000/docs

## Тестирование ⚡️  
Тестируйте свое API с помощью pytest. По умолчанию тесты запускаются локально:  
pytest

При желании изменить адрес API, добавьте аргумент:  
pytest --baseUrl=http://localhost:8000

Теперь ваш проект готов к работе! Приятного кодинга 😊
